# Práctica 01. vscode-extensiones

## Objetivos

Buscar extensiones del visual studio para los lenguages de programacion que vamos hacer este año

## Extension 1 - Unity

### .Net install Tool

#### Extension que instala y maneje diferentes versiones de .NET SDK y Runtime

### C#

#### Añade soporte para C#

## Extension 2 - Javascript

### JavaScript (ES6) code snippets

#### Extension  que sirve para crear una plantilla de codigo.

### ESLint

#### extension que integra eslint para encontrar errores de javascript.

## Extension 3 - Typecript

### Pretty TypeScript Errors

#### Extension para que los errores de typescript sean mas legible.

### JavaScript Booster

#### Es una Extension utilizada para refactorizar el codigo de forma rapida

## Extension 4 - React y React native

### ES7 React/Redux/GraphQL/React-Native snippets

#### Extension  que sirve para crear una plantilla de codigo de react native .

### Expo Tools

#### Esta extension es para que te sugestiones del config del expo y para ver preview de archivos.

### React Native Tools

#### Esta extension añade commandos para debuggear React native
